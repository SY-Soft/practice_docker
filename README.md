# Практика с Docker

- docker stack
- nginx wildcard домены - авто создание  доменов * .localhost
- 2 заглушки для тестов + тренировочный проект laravel + Drupal 11

- поддерживает Laravel
- поддерживает Drupal 8/9/10/11
- автоматически определяет web root


### Исправлена работа Laravel cache в Docker Desktop

В некоторых конфигурациях Docker Desktop (WSL2/9p mount) Laravel не может выполнять атомарное переименование файлов в `bootstrap/cache`, что приводит к ошибкам вида:

```
rename(...): Permission denied
```

Для решения проблемы каталог `bootstrap/cache` автоматически переносится во внутреннюю файловую систему контейнера.

При запуске контейнера для каждого Laravel-проекта создаётся отдельный каталог:

```
/var/cache/laravel/<project-name>
```

и подключается через символическую ссылку:

```
bootstrap/cache -> /var/cache/laravel/<project-name>
```

Это устраняет проблемы с `rename()`, сохраняет исходники на хостовой машине и не требует изменений в самих проектах Laravel.
